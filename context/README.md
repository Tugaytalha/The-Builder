# Context

Reference material for the Freya "Build the Builder" hackathon (10–11 October 2026). Read from here before you plan or build. Do not edit these files to fit the code: they are the source of truth.

| Path | What it is | Read it for |
| --- | --- | --- |
| `hackathon/overview.md` | The Overview tab of the hackathon page | The task, the schedule (all times UTC), what counts |
| `hackathon/data.md` | The Data tab | The kit file list, how one case runs, the 13 practice cases in full |
| `hackathon/evaluation.md` | The Evaluation tab | The three checks, the final benchmark, tie-breaks, how to score yourself |
| `hackathon/submit.md` | The Submit tab | The submission form, the builder trace, verification, limits |
| `hackathon/rules.md` | The Rules tab | Entry rules and prizes |
| `hackathon/faq.md` | The FAQ tab | Answers to common questions |
| `hackathon/leaderboard.md` | The Leaderboard tab | Empty until the results are out |
| `kit/` | The organizers' kit, version 3, an exact copy | Start with `kit/README.md`. Briefs, tool API, Freya docs, `freya.py`, practice cases, scorer |
| `kickoff-transcript.md` | The kickoff call transcript, verbatim | What the organizers said live, and the participants' questions |
| `tt-bench-paper.md` | The τ^τ-bench paper, the basis of the benchmark method | How builder agents fail, and what the best builders do |
| `sources/` | The original `Tt-bench.pdf` and `kickoff-transcript.rtf` | The paper figures, which the Markdown keeps only as captions |

Source of the `hackathon/` files: https://www.freyavoice.ai/hackathon, fetched 2026-10-10. The page can change during the event. To refresh it, fetch the page again and compare.
