# The-Builder

Our entry for the Freya "Build the Builder" hackathon.

All hackathon context lives in `context/`. Read `context/README.md` first: it lists each file and what to read it for. The rules, the schedule, the submission format, and the kit are there.

`kit/` is our working copy of `context/kit/`. Run the kit from there. Never write into `context/`.

What we measured so far, the testing rules we learned, and the setup that works are in `notes/example-builder-baseline.md`. Read it before you build or test. The raw data is in `runs/`.
